# Project canon

The settled facts of DarkNESS-LE: what it models, the units, the assumptions,
and where each number comes from. Code and docstrings are the detail; this is
the short version that should stay true.

| File | Holds |
|---|---|
| [project.md](project.md) | Goal, scope, what is out of scope |
| [units.md](units.md) | Units, frames, constants |
| [models.md](models.md) | One entry per module: model and key assumptions |
| [references.md](references.md) | Published sources and whether each is verified by a test |
| [decisions.md](decisions.md) | Design rules the code follows |

**Updating:** change the canon in the same commit as the code that changes
it. Keep entries short. If a fact is in a docstring, point to it rather than
copying it.
